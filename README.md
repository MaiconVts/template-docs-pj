# template-docs-pj

Template corporativo de documentação para projetos de desenvolvimento de software sob regime de **Pessoa Jurídica (PJ)**. Cobre o ciclo de vida completo do projeto — do alinhamento inicial com o cliente até o encerramento formal com termo de aceite assinado.

---

## Conteúdo

Todos os documentos estão organizados na pasta [`/docs`](./docs/).

| # | Documento | Fase |
| :--- | :--- | :--- |
| 01 | Visão Geral e Contexto | Alinhamento |
| 02 | Especificação do Projeto | Alinhamento |
| 03 | Termo de Aceite Inicial e Trava de Escopo | Alinhamento |
| 04 | Metodologia e Processo de Trabalho | Planejamento |
| 05 | Cronograma de Entregas | Planejamento |
| 06 | Projeto de Interface (UI/UX) | Design e Arquitetura |
| 07 | Arquitetura da Solução e Infraestrutura | Design e Arquitetura |
| 08 | Template Padrão da Aplicação | Design e Arquitetura |
| 09 | Plano de Testes de Software | Validação Técnica |
| 10 | Registro de Testes de Software | Validação Técnica |
| 11 | Plano de Testes de Usabilidade | Validação com Usuários |
| 12 | Registro de Testes de Usabilidade | Validação com Usuários |
| 13 | Termo de Aceite Final e Encerramento | Encerramento |

Para instruções de uso, convenções e fluxo de preenchimento, consulte o [`/docs/README.md`](./docs/README.md).

---

## Fundamentos

O template é fundamentado em práticas reconhecidas pelo mercado:

- **PMBOK** — Gerenciamento de cronograma, estimativas e reservas de risco
- **ISO/IEC 25010** — Qualidade de produto de software
- **LGPD** — Conformidade no tratamento de dados pessoais
- **OWASP Top 10** — Segurança em aplicações web
